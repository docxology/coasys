# Abstract

Coasys Ops is a local control plane for the public Coasys repository fleet.
It combines repository inspection, a SQLite inventory, a command-line
interface, and a local dashboard. Its Weave document model describes the
relationships among repositories and produces dependency-ordered plans
and deployment-readiness reports. This software manuscript explains the
implementation and the evidence supplied by local Git fixtures, temporary
configuration files, and API tests.
